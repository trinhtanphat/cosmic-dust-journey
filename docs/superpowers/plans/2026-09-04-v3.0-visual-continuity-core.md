# V3.0 Visual Continuity Core Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the existing ten-chapter stellar journey visually continuous across chapter boundaries without changing chapter order or scientific copy.

**Architecture:** Add a pure deterministic continuity model and a global camera spline between chapter/cinematic state and scene rendering. `SceneDirector` remains the only scene-family selector, `ExperienceCanvas` remains the only renderer/frame-loop owner, and existing V2.1 adaptive quality, WebGL recovery, observability, accessibility, and fallback behavior remain authoritative.

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Three.js 0.185, React Three Fiber 9, Zustand, Vitest, Node core tests, Playwright Chromium.

**Spec:** `docs/superpowers/specs/2026-09-04-v3.0-visual-continuity-core-design.md`

## Global Constraints

- Preserve exactly ten semantic chapter IDs and their current order.
- Do not rewrite authored scientific copy in `src/content/chapters.ts`.
- `elsewhere` remains an alternate stellar outcome; white-dwarf matter must not physically transfer into black-hole accretion.
- Do not add a second renderer, frame loop, chapter timeline, or state store.
- Continuity resolvers must be pure, deterministic, and clamp invalid numeric input.
- Existing V2.1 adaptive-quality budgets remain hard limits.
- Reduced motion preserves narrative order and matter relationships while reducing camera/deformation amplitude.
- Existing WebGL recovery, renderer isolation, semantic DOM fallback, muted-audio policy, and privacy-first observability remain intact.
- No reference-site assets, shaders, text, or proprietary implementation may be copied.
- Normal rendering mounts no more than current and next scene families.
- V3.2 pixel-baseline capture is out of scope for V3.0.
