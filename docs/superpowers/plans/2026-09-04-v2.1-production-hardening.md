# Cosmic Dust Journey V2.1 Production Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden V2.0 for production with privacy-first observability, optional external telemetry, deterministic diagnostics, bounded WebGL/render/audio recovery, and CI evidence without changing cinematic or narrative semantics.

**Architecture:** Add a provider-neutral observability subsystem under `src/observability/`. One frame stream continues to drive `observeFrame()` and also records diagnostics; React, WebGL, audio, navigation, and quality emit sanitized events to an `ObservabilityHub`. External adapters are optional, lazy/conditional, circuit-broken, and cannot affect rendering or narrative progress. Failure boundaries degrade only the renderer to the existing DOM-preserving fallback.

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Three.js 0.185, React Three Fiber 9, GSAP, Zustand 5, WebAudio, Node core tests, Vitest/jsdom, Playwright Chromium desktop + Pixel 7, GitHub Actions. Optional Sentry browser SDK is dynamically imported only when enabled.

**Spec:** `docs/superpowers/specs/2026-09-04-v2.1-production-hardening-design.md`

## Global Constraints

- Default telemetry mode is local-only; external telemetry is OFF unless explicitly enabled by deployment environment.
- Never collect pointer coordinates, narrative text, arbitrary query/hash data, form data, email/account/device identifiers, user IDs, or browser-storage contents.
- DNT/GPC suppress analytics providers; local diagnostics remain enabled. Error reporting is independently configurable but uses the same sanitizer.
- No scene/component may directly call Sentry, Plausible, or GA4.
- Existing chapter ids, scene ids, cinematic phase semantics, scroll timing, interaction outcomes, adaptive-quality thresholds, and muted-audio consent behavior remain unchanged.
- Keep exactly one authoritative frame stream. Observability reads frame samples; it does not create a competing FPS loop.
- Normal runtime provider failures are fail-open from the application perspective and cannot recurse back through the hub.
- WebGL recovery is bounded to one restore attempt; a second loss enters session fallback.
- GitHub Pages base-path and `/src/main.tsx` artifact guards remain intact.
- No real DSN, analytics measurement id, API key, or secret is committed.
- Work stays on `feature/v2.1-production-hardening`; no force/bypass merge.
