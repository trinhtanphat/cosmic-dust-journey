# Cosmic Dust Journey V2.1 Production Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Harden V2.0 for production with privacy-first observability, optional external telemetry, deterministic diagnostics, bounded WebGL/render/audio recovery, and CI evidence without changing cinematic or narrative semantics.

**Architecture:** Add a provider-neutral observability subsystem under `src/observability/`. The existing React Three Fiber frame callback remains the single frame-timing stream and feeds both adaptive quality and local diagnostics. React, WebGL, audio, navigation, and quality emit sanitized events to an `ObservabilityHub`; external adapters are attached lazily, circuit-broken independently, and cannot affect rendering or narrative progress. Runtime renderer failures degrade only the visual subsystem to the existing DOM-preserving fallback.

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Three.js 0.185, React Three Fiber 9, GSAP, Zustand 5, WebAudio, Node core tests, Vitest/jsdom, Playwright Chromium desktop + Pixel 7, GitHub Actions. Optional Sentry support uses `@sentry/browser` through dynamic import only when enabled.

**Spec:** `docs/superpowers/specs/2026-09-04-v2.1-production-hardening-design.md`

## Global Constraints

- Default telemetry mode is local-only; external telemetry is OFF unless explicitly enabled by deployment environment.
- Never collect pointer coordinates, narrative text, arbitrary query/hash data, form data, email/account/device identifiers, user IDs, or browser-storage contents.
- DNT/GPC suppress analytics providers; local diagnostics remain enabled. Error reporting is independently configurable but uses the same sanitizer.
- No scene/component may directly call Sentry, Plausible, or GA4.
- Existing chapter ids, scene ids, cinematic phase semantics, scroll timing, interaction outcomes, adaptive-quality thresholds, and muted-audio consent behavior remain unchanged.
- Keep exactly one authoritative frame stream. Observability reads the existing frame sample; it does not create a competing RAF/useFrame loop.
- Provider failures are fail-open from the app perspective, bounded per adapter, and never recursively reported through the same hub.
- WebGL recovery is bounded to one restore attempt; a second loss or restore timeout enters session fallback.
- GitHub Pages base-path and `/src/main.tsx` artifact guards remain intact.
- No real DSN, analytics measurement id, API key, or secret is committed.
- Work stays on `feature/v2.1-production-hardening`; no force/bypass merge.
